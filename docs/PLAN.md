## 2. 视觉系统

**母题：一条声音的线**。平直、黑白 → 2007.08.31 有了颜色 → 分成多股 → 被弹幕缠绕 → 被公式复制 → 焦黑 → 埋进沙里 → 被镜像 / 自我复制 → 汇成光环 → 静音里重归平直 → 无数条线一起振动。

**颜色就是历史**：2007 年以前只有黑白（MEIKO 红、KAITO 蓝只出现在色块上）。每个声库登场带进自己的颜色：初音青 #39C5BB、镜音黄 #FFC400 / 橙 #FF9A00、巡音粉 #FF8FB1、GUMI 绿、洛天依蓝。焦土章节颜色被烧掉，砂星章节只剩沙色，终章所有颜色同时出现。

**年份时钟**：全片常驻（样片里左下角的大号计数器），各章缩小移到角落，冲击镜头时放大。

**题眼字**：每章一个大号汉字踩拍硬切（明朝体 Black）：声 / 初音未来 / 融 / 息 / 名 / 燃 / 砂 / 问 / 唱。

**曲目卡**的三种形态：
- **S 级 · 主镜头**（2–4 小节）：这首歌的视觉隐喻占满画面，另有一张大号曲名卡（曲名 + P 主 + 年份 + 声库色条）。有 `covers/<id>.png` 时放进画框槽位。
- **A 级 · 快切**（2 拍 ≈ 1 秒）：只有曲名 / P 主 / 年份 + 声库色条，踩鼓点连切；每张卡配一个小动作（旋转、嵌套、像素化……）。
- **B 级 · 名字墙**：只出现在弹幕层、档案墙、终章光环和片尾滚动里。

**字体**：日文用 Noto Sans / Serif JP，拉丁字母用 Archivo，数字和标签用 IBM Plex Mono（都已在工程里）。
